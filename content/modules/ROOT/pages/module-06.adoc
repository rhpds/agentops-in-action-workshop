= Module 6: Let the Agent Reach the Docs Website
:page-duration: TBD

// Overview: Participants find that the agent's documentation-reading skill can no longer reach the
// external site it depends on. They open network access in OpenShell policy, then see the risk of
// opening it too broadly: the agent can now browse the entire internet, including a compromised
// look-alike site. An attack where the real documentation site redirects to a malicious page shows why
// the policy needs to name specific endpoints, not just a whole domain.

== Objectives

* Diagnose why the agent's documentation-reading skill can no longer reach the external site it depends
  on
* Update the OpenShell network policy to allow external traffic (all to start with)
* See an attack where the real documentation site accidentally redirects to a malicious page in one of its instructions
** Understand the risk of opening network access too broadly: the agent could suddenly reach the entire
  internet, including a look-alike, compromised site
* Scope the policy down to the specific endpoints the agent needs, not an entire domain
* Bonus: Eval uses a skill that requires another website, which you need to give access to as well
