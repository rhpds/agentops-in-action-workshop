= Module 5: Let the Agent Write Files
:page-duration: TBD

// Overview: Participants find the agent can't create a report because it can't write to the filesystem
// at all. They're introduced to OpenShell filesystem policy with a first, overly broad example that
// allows every filesystem action, then find exactly where the agent needs to write and narrow the
// policy to just that. Two attacks -- deleted reports and a tampered configuration -- show why
// narrowing down to specific file-creation actions matters.

== Objectives

* Diagnose why the agent can no longer create a report
* Get introduced to OpenShell filesystem policy, starting from an example that allows every filesystem
  action
* Find exactly where in the filesystem the agent needs to write its report
* Update the policy to allow that, and confirm the agent can create reports again
* See two attacks an overly broad filesystem policy allows: reports being deleted, and the agent's
  configuration being tampered with
* Narrow the policy down to just the specific file-creation actions the agent needs (touch, mkdir, and
  similar)
