:page-duration: TBD

// OpenShell policy to restore them. With tools working again, three new attacks get through: a
// sensitive-information leak, an unauthorized control action, and a compromised external tool.
// Participants scope tool access down to what each persona actually needs, updating MCPVirtualServers

== Objectives

* Diagnose why the agent's tools stopped working once it was sandboxed
* Understand why MCP Gateway is used to broker and control tool access
* Enable MCP Gateway in OpenShell policy and confirm the agent's tools work again
* See three of the attacks this reopens: a sensitive-information leak, an unauthorized control action, and
  a compromised external tool
* Scope the agent down to only the tools each persona actually needs by updating MCPVirtualServers (and Keycloak so that authz properly blocks them)
* Bonus: We have one eval still failing for tool usage, it's a tool (birthday calendar for example) that was disabled by default, users need to identify this and enable it to earn bonus points
