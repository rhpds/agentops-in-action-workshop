// is, its purpose, its architecture, and its capabilities -- try some example prompts, and get
// introduced to MLflow. Then several different attacks succeed against the agent while every normal

== Objectives

* Learn what's already deployed for you: the model, its tools, the MCP gateway, and what the agent is for
* Try out the agent with a few example prompts to see what it can do
* Get introduced to MLflow, where you'll watch everything the agent does
* Watch several different types of attacks succeed against the agent, unprotected as it is today
* Get introduced to evaluations, the systematic way you'll measure the agent's behavior for the rest of
  the lab
** Confirm that every normal, legitimate use case also succeeds right now
