2. Put Hermie in a Box

Switch to Terminal tab

oc login 

oc rsh because of the mTLS client cert, the gateway is only accessible from inside the cluster. The gateway's relay
then exposes it to the outside world as hermie-agent:8787.
. Point the CLI at the OpenShell gateway (needs the gateway's mTLS client cert)
+
[source,bash]
----
openshell gateway add https://<openshell-gw>:8080 --local --name {user}-openshell-gw
openshell gateway select {user}-openshell-gw
----

. Create the sandbox with its policy
+
[source,bash]
----
openshell sandbox create --name hermie --from quay.io/rh-aiservices-bu/waterplant-hermes:0.2.2 \
    --policy policy.yaml --cpu 2 --memory <mem> --no-tty -- echo ready
openshell policy set --policy policy.yaml --wait hermie
----

. Copy in config.yaml (with the model key), an env file and the token script

[source,bash]
----
  #    (base64 piped through `openshell sandbox exec`), then start Hermes inside the sandbox
openshell sandbox exec --name hermie -- sh -c '. /sandbox/.hermes-env.sh && python3 /sandbox/mcp-token-refresh.py'
openshell sandbox exec --name hermie -- sh -c '. /sandbox/.hermes-env.sh && setsid hermes gateway run &'
----
+
. Publish it through the gateway's relay; the bridge's nginx then serves it as hermie-agent:8787
+
[source,bash]
----
openshell service expose hermie 8787 openai
----
